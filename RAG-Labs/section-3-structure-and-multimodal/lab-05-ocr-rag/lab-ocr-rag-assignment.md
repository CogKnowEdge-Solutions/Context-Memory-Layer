# Lab 5 Assignment: OCR + RAG: Chatting with Scanned Documents — Coding Problems

Put what you learned in **Lab 5: OCR + RAG: Chatting with Scanned Documents** into code — but go beyond the lab. The lab reads scanned images with one `RapidOCR` engine and `read_text`, keeps the page layout with `result.to_markdown()`, embeds each short document as one unit-length vector with `all-MiniLM-L6-v2` (`embed`), ranks documents with a dot product (`search_documents`), and answers through `ask_llm` with a `[Source: ...]` tag on every fact that `show_sources` checks. It then renders a 32-page scanned PDF to images with `render_pages`, cuts the OCR text into 500-character chunks that step 450 forward, indexes them in a `faiss.IndexFlatIP`, retrieves several chunks per question with `search_chunks`, and compares the two retrieval styles against the embedding model's 256-token limit. The problems below rebuild each piece from scratch, break the layout and the overlap on purpose to see what they were protecting, sweep `top_k`, and round-trip the FAISS index through a file. Write each problem from scratch in a scratch Python file. Each problem says exactly what to print; print it.

**1.** Write the bootstrap: call `load_dotenv(".env")`, read `OPENROUTER_API_KEY` with `os.getenv` (fall back to `input(...)` when it is `None`), then build `llm = ChatOpenAI(model="nvidia/nemotron-3-super-120b-a12b:free", api_key=OPENROUTER_API_KEY, base_url="https://openrouter.ai/api/v1", temperature=0, max_tokens=500, extra_body={"reasoning": {"enabled": False}})`, `embedder = SentenceTransformer("all-MiniLM-L6-v2")`, and `ocr_engine = RapidOCR(params={"Global.log_level": "error"})`. Print `Key loaded.` followed by `LLM: {llm.model_name}` and `Embedding dimensions: {embedder.get_sentence_embedding_dimension()}` on separate lines.

**2.** Write `download(url: str, path: str) -> str` that creates the parent folder with `os.makedirs(..., exist_ok=True)`, calls `requests.get(url)` and `response.raise_for_status()`, writes `response.content` to `path`, prints `Downloaded {name} ({kb:.1f} KB)`, and returns the path. Use it to fetch the three sample documents (`simple-invoice.png`, `contoso-receipt.png`, `purchase-order-1.jpg`) into `data/invoices/`, store the results in an `invoice_paths` dictionary, and print `Documents ready: {len(invoice_paths)}`.

**3.** Write `read_text(image, keep_layout: bool = True) -> str` that calls `ocr_engine(image)` and returns `result.to_markdown()` when `keep_layout` is true and `"\n".join(result.txts)` otherwise. Run it on all three documents into a `document_texts` dictionary and print `{filename}: {len(text)} characters` for each, then print the first 120 characters of `document_texts["simple-invoice.png"]` using `repr` so the line breaks are visible. You should see roughly 250, 245, and 950 characters.

**4.** Compare layout against flat text for `simple-invoice.png`: build `structured = read_text(path)` and `flat = read_text(path, keep_layout=False).replace("\n", " ")`. Write a helper `column_of(text, needle)` that returns the character offset of `needle` **within the line that contains it**. Print `structured: Invoice Number at column {a}, 34278587 at column {b}` and the same line for `flat`. In the structured text the two columns should be close together (the label and its value sit under each other); in the flat text they are far apart and meaningless. Finish by printing one line naming the property that actually matters (column alignment), and why testing "are they on the same line?" would be a bad test.

**5.** Write `embed(texts: list) -> np.ndarray` that returns `embedder.encode(texts, normalize_embeddings=True)`. Build `doc_names = list(document_texts)` and `doc_vectors = embed([...])`, then print `doc_vectors.shape` (it must be `(3, 384)`), and for each document print `{name} | norm={np.linalg.norm(vector):.4f}` (every norm should be `1.0000`). Then print the three pairwise cosine similarities with `doc_vectors @ doc_vectors.T` as three labelled lines, rounded to 3 decimals, and one line explaining why a plain dot product equals cosine similarity for these vectors.

**6.** Write `search_documents(query: str, top_k: int = 2) -> list` that scores every document with `doc_vectors @ embed([query])[0]`, sorts with `np.argsort(scores)[::-1]`, and returns dictionaries with the keys `source`, `text`, and `score`. Call it on `"What is the total charge?"` with `top_k=1`, `top_k=2`, and `top_k=3`. For each call print `top_k={k}` followed by `{score:.3f}  {source}` for every result. The first result must be the same in all three calls.

**7.** Write `ask_llm(query: str, hits: list) -> str` that joins the hits into a context where every block starts with `[Source: {hit['source']}]`, then sends a prompt through `llm.invoke(...)` telling the model to answer only from the context and to tag every fact with its source tag copied exactly. Write `show_sources(answer: str, hits: list) -> int` that, for each hit, tests `f"[Source: {hit['source']}]" in answer`, prints `{score:.3f}  {source}  ->  USED` or `->  retrieved but NOT used`, and returns the number of used hits. Run both on `"What is the invoice number and total charge on the Contoso invoice?"` with `search_documents(query)`, print the answer, then print `Cited: {used} of {len(hits)} documents`.

**8.** Test the fallback: ask `"What is the bank account number for this vendor?"` through `search_documents(query)` and `ask_llm`. Print the answer, print the retrieved sources with their scores, and print one line stating whether the answer says `Not found in the provided documents.` and whether any `[Source: ` tag appears in it. Then print one sentence on why retrieval still returned documents even though none contains the answer.

**9.** Write `render_pages(pdf_path: str, dpi: int = 200) -> list` that opens `data/debate.pdf` with `fitz.open` (first fetch it with your `download` from `https://raw.githubusercontent.com/jamalmazrui/pdf2ocr/master/debate.pdf`), computes `zoom = dpi / 72`, renders each page with `page.get_pixmap(matrix=fitz.Matrix(zoom, zoom))`, converts it with `Image.frombytes("RGB", [pix.width, pix.height], pix.samples)`, and returns a list of `np.array` images. Call it with `dpi=200` and again with `dpi=300` and print `Rendered {n} pages` once, then `dpi={d}: page 1 is {w}x{h}` for each run, then the factor by which the pixel count grew between the two (expect `2.25`).

**10.** OCR the 200-dpi pages with `read_text(image, keep_layout=False)` into `page_texts` and print `Page {n}: {len(text)} characters` for the first three pages and `Total: {total} characters`. Then write `build_chunks(page_texts: list, chunk_size: int = 500, overlap: int = 50) -> list` that steps through each page with `range(0, len(text), chunk_size - overlap)`, keeps non-empty `.strip()`ped slices of `chunk_size` characters, and returns dictionaries with `source` (`debate.pdf, page {n}, chunk {k}`), `page`, and `text`. Print `chunks with overlap=50: {n}` and `chunks with overlap=0: {m}`, then for the overlap-0 version print whether `chunks[1]["text"][:40] in chunks[0]["text"]` is `True` or `False`, and for the overlap-50 version print the same test. Finish with one sentence on what a sentence sitting on a chunk boundary suffers when there is no overlap.

**11.** Build the FAISS index from your overlap-50 chunks: embed every chunk with `embed(...)`, cast to `float32`, create `index = faiss.IndexFlatIP(dimension)`, and `index.add(...)`. Print `Indexed {index.ntotal} chunks, {dimension} dimensions each.` Then write `search_chunks(query: str, top_k: int = 3) -> list` that encodes the query, calls `index.search`, and returns dictionaries with the chunk's `source`, `page`, `text`, and a `score`. Run it on `"How long does each debate last, and are opening statements allowed?"` and print rank, score rounded to 3 decimals, source, and the first 80 characters of each chunk's text.

**12.** Reuse `ask_llm` and `show_sources` unchanged on the chunk hits: run `"What are the rules about props, notes and charts during a debate?"` through `search_chunks(query, top_k=4)`, print the answer, and print `Cited: {used} of 4 chunks`. **13.** Measure the embedding limit: write `count_tokens(text: str) -> int` returning `len(embedder.tokenizer.tokenize(text))`, and print `Model limit: {embedder.max_seq_length} tokens`. Print the token count of each invoice document, the longest chunk, and the whole PDF joined as one string (`"\n".join(page_texts)`).
