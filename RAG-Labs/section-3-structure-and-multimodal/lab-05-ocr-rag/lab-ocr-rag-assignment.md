# Assignment: OCR + RAG: Chatting with Scanned Documents — Coding Problems

Put what you learned in **OCR + RAG: Chatting with Scanned Documents** into code — but go beyond the lab. The lab reads scanned images with one `RapidOCR` engine and `read_text`, keeps the page layout with `result.to_markdown()`, embeds each short document as one unit-length vector with `all-MiniLM-L6-v2` (`embed`), ranks documents with a dot product (`search_documents`), and answers through `ask_llm` with a `[Source: ...]` tag on every fact that `show_sources` checks. It then renders a 32-page scanned PDF to images with `render_pages`, cuts the OCR text into 500-character chunks that step 450 forward, indexes them in a `faiss.IndexFlatIP`, retrieves several chunks per question with `search_chunks`, and compares the two retrieval styles against the embedding model's 256-token limit. The problems below rebuild each piece from scratch, break the layout and the overlap on purpose to see what they were protecting, sweep `top_k`, and test how chunk size interacts with the embedding model's token limit.

**How to work:**

- Write each problem from scratch in a scratch Python file, and keep one session open.
- Environment, API-key and LLM setup are not repeated here: reuse the setup from the first assignment (Classical RAG).
- Each problem says exactly what to print; print exactly that.
- Numbers marked as expected come from the lesson's run; OCR and LLM output can differ slightly, so report what you actually saw.
- When a problem asks you to predict, write the prediction as a comment before you run the code.

**State dependencies:** later problems reuse names from earlier ones, so run them in order in one session. `llm` comes from the first assignment's setup; `ocr_engine` and `embedder` from Problem 1; `download` and `invoice_paths` from 2; `read_text` and `document_texts` from 3; `embed`, `doc_names`, `doc_vectors` from 5; `search_documents` from 6; `ask_llm` and `show_sources` from 7; `page_images` from 9; `page_texts` and `build_chunks` from 10; `index` and `search_chunks` from 11; `count_tokens` from 13. Problems 7 and 12 call the LLM and need the working API key from the first assignment; Problems 2 and 9 need internet access to download files.
