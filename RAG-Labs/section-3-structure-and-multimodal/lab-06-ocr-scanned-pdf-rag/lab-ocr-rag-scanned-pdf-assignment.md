# Lab 6 Assignment: Automated Document Q&A: OCR + RAG on a Scanned PDF (OpenRouter) — Coding Problems

Put what you learned in **Lab 6: Automated Document Q&A: OCR + RAG on a Scanned PDF (OpenRouter)** into code — but go beyond the lab. The lab built a pipeline that renders `data/debate.pdf` page by page with `fitz` at a `200 / 72` zoom, reads the words out of each image with `easyocr.Reader(["en"], gpu=False)` using `readtext(page_array, detail=0)`, slices the text into 500-character chunks that step forward 450 at a time, embeds them with `all-MiniLM-L6-v2`, stores the vectors in a `faiss.IndexFlatL2`, and answers through `openai/gpt-oss-20b:free` with a `--- FINAL ANSWER ---` block plus a per-page `--- EXPLAINABILITY ---` breakdown. The problems below rebuild each stage as its own function, re-render the same page at two zooms to see how pixel size changes OCR output, run `readtext` with `detail=1` to read real confidence scores back instead of trusting `detail=0`, set `chunk_size` equal to the window to deliberately destroy the 50-character overlap, sweep `k` in a `search_with_scores` that also prints FAISS distances, send a payload with a nonexistent model id to inspect the real HTTP error, and round-trip the index through `faiss.write_index` and `faiss.read_index`. Write each problem from scratch in a scratch Python file. Each problem says exactly what to print; print it.

**1.** Write the environment bootstrap: prompt for the key with `input("Please enter your OpenRouter API key manually: ")`, store it in `OPENROUTER_API_KEY`, set `OPENROUTER_URL = "https://openrouter.ai/api/v1/chat/completions"` and `TEXT_MODEL = "openai/gpt-oss-20b:free"`, then assert the key is non-empty. Print the line `Models to use: openai/gpt-oss-20b:free`.

**2.** Write the download step from scratch: `requests.get` the URL `https://raw.githubusercontent.com/jamalmazrui/pdf2ocr/master/debate.pdf`, call `r.raise_for_status()`, `os.makedirs("data", exist_ok=True)`, and write the bytes to `data/debate.pdf` inside a `try`/`except` that prints `Error downloading PDF: {e}` on failure. On success print `Success! Saved PDF to: data/debate.pdf` and the byte count on the next line.

**3.** Write `render_pages(pdf_path: str, dpi: int = 200) -> list` from scratch: `fitz.open` the file, compute `zoom = dpi / 72`, build `matrix = fitz.Matrix(zoom, zoom)`, and for each page call `page.get_pixmap(matrix=matrix)` and `Image.frombytes("RGB", [pix.width, pix.height], pix.samples)`, then `doc.close()`. Call it on `data/debate.pdf` and print `Success: Converted {len(pages)} pages into images.` followed by `Page 1 size: {width}x{height}`.

**4.** Call `render_pages` twice — once with `dpi=200` and once with `dpi=300` — and print the pixel width and height of page 1 for each run on separate lines. Then print one line computing and stating by what factor the pixel count grew between the two renders, since that is what ultimately bounds OCR accuracy.

**5.** Write `ocr_page(reader, page_img) -> str` from scratch: convert the image with `np.array`, call `reader.readtext(page_array, detail=0)`, and `"\n".join(lines)`. Run it on page 1 of the `dpi=200` renders with `ocr_reader = easyocr.Reader(["en"], gpu=False)` and print `Page 1 transcribed! Found {len(text)} characters.` on one line and `OCR lines: {len(lines)}` on the next.

**6.** Re-run OCR on the same page with `detail=1` instead, then compute the mean confidence across the first element of every detection tuple. Print `Detections with detail=1: {count}` and `Mean confidence: {mean:.3f}`, and then one line explaining in a single sentence what the lab throws away by choosing `detail=0`.

**7.** Write `build_chunks(pages, reader, test_page_limit=2, chunk_size=450, window=500) -> list[dict]` from scratch: for each page build `np.array(page_img)`, join the `detail=0` lines into `full_page_text`, then slice `full_page_text[start_idx : start_idx + window]` in `range(0, len(full_page_text), chunk_size)` steps and append `{"page": i, "text": piece}` for every non-empty piece. Print `Total chunks created: {len(chunks)}`, a per-page chunk count line for each page, and the last 50 characters of `chunks[0]["text"]` and the first 50 characters of `chunks[1]["text"]` on separate lines to show the shared overlap.

**8.** Deliberate debugging exercise: call `build_chunks` a second time with `chunk_size=500` and `window=500` so consecutive chunks no longer overlap, and print the same two 50-character windows again. Then print one line explaining in a single sentence what happens to a sentence that straddles a chunk boundary once the 50-character overlap is gone.

**9.** Write the indexing step from scratch: pull `chunk_texts = [c["text"] for c in chunks]`, embed with `embed_model.encode(chunk_texts, convert_to_numpy=True)` using `SentenceTransformer("all-MiniLM-L6-v2")`, then build `index = faiss.IndexFlatL2(embeddings.shape[1])` and `index.add(embeddings)`. Print `Vector dimension: {embeddings.shape[1]}`, `Chunks embedded: {embeddings.shape[0]}`, and `Success: Indexed {index.ntotal} chunks into the database.`

**10.** Write `search_with_scores(question: str, index, chunks, k: int = 3) -> list[tuple]`, a variation of `retrieve_documents` that keeps the distances the lab throws away: encode the question, run `index.search(q_vec, k)`, and return `(distance, chunk_index, chunk)` triples. Run it with `k=3` for the question `"What was the main topic of the debate?"` and print, for each hit, the rank, the raw L2 distance rounded to two decimals, the page number, and the first 80 characters of the chunk text.

**11.** Write `execute_rag_pipeline(question: str) -> str` from scratch: call your `search_with_scores` with `k=3`, return `"No sources found."` when nothing comes back, build `context_block` by joining `f"--- Context Block (Page {c['page']}) ---"` headers with each chunk's text, and post a prompt demanding exactly two sections — `--- FINAL ANSWER ---` and `--- EXPLAINABILITY ---` — to `openai/gpt-oss-20b:free` at `temperature=0.0`. Print `Asking AI: 'What was the main topic of the debate?'`, print the returned text, then print two booleans on separate lines confirming the reply contains `--- FINAL ANSWER ---` and `--- EXPLAINABILITY ---`.

**12.** Sweep the retrieval width and read the state back: call `search_with_scores` for the same question with `k=1`, `k=3`, and `k=7`, and for each print `k={k} | chunks: {n} | distinct pages: {pages}`. Then print one line stating whether raising `k` past the number of indexed chunks can ever change the answer, given `index.ntotal`.

**13.** Deliberately break the LLM call: reuse the same prompt and headers from problem 11 but set `"model"` to the nonexistent id `"openai/does-not-exist:free"`, keep `resp.raise_for_status()`, and wrap the post in `try`/`except Exception as e`. In the handler print `HTTP status: {resp.status_code}` and `Provider error: {resp.json()['error']['message']}` on the next line, so you can see exactly what a rejected OpenRouter request returns.

**14.** Prove the index is persistable: write `save_index(index, path)` using `faiss.write_index(index, path)` and `load_index(path)` using `faiss.read_index(path)`, save to `data/faiss.index`, then load a brand-new index from that file and run the same search for the query `"What was the main topic of the debate?"` through it with `k=1`. Print `Reloaded index size: {index.ntotal}` and `Top-1 chunk matches in-memory run: {True or False}`.
