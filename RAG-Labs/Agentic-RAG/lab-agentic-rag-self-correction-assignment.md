# Lab 13 Assignment: Agentic RAG with Self-Correction — Coding Problems

Put what you learned in **Lab 13: Agentic RAG with Self-Correction** into code — but go beyond the lab. The lab built a LangGraph agent that retrieves chunks with `cosine_similarity`, grades them with an LLM, rewrites the question and loops back when the grade is `NO`, then answers in a `--- FINAL ANSWER ---` / `--- EXPLAINABILITY ---` format. The problems below go past that: they swap the model, vary the chunk and top-k parameters, hand-seed and read back state that the graph never actually produced, break the grade guard and the retry cap on purpose, and watch the loop's intermediate states instead of trusting the final one. Write each problem from scratch in a scratch Python file. Each problem says exactly what to print; print it.

**1.** Write the environment bootstrap: load `.env` with `python-dotenv`, then assert `OPENROUTER_API_KEY` is set and non-empty. Print `✓ All environment variables loaded successfully`.

**2.** Configure two `ChatOpenAI` clients against `https://openrouter.ai/api/v1` with `temperature=0.0` — one on `openai/gpt-oss-20b:free` and one on `nvidia/nemotron-3-super-120b-a12b:free` — and print `LLM configured successfully!` followed by each client's `model_name` on its own line.

**3.** Download `https://arxiv.org/pdf/1706.03762.pdf` with `requests`, write the bytes to `data/downloaded_paper.pdf`, then extract text with `pypdf.PdfReader` and stop as soon as `len(document_text) >= 1500`, truncating to exactly 1500 characters. Print `Extracted {len(document_text)} characters of text.` and, on the next line, the first 80 characters of `document_text`.

**4.** Split `document_text` with `RecursiveCharacterTextSplitter(chunk_size=300, chunk_overlap=50, separators=["\n\n", "\n", ".", " ", ""])` and print `Knowledge base ready with {len(knowledge_base)} intelligent chunks.` Then verify the overlap actually exists by checking whether the last 50 characters of `knowledge_base[0]` appear inside `knowledge_base[1]`, and print `Overlap preserved: True` or `Overlap preserved: False` based on that check.

**5.** Load `HuggingFaceEmbeddings(model_name="all-MiniLM-L6-v2")`, embed `knowledge_base` with `embed_documents`, then embed the query `"How does the Transformer work?"` with `embed_query`. Print `Chunks embedded successfully!`, the vector dimension of the first chunk, and the top 3 chunk indices with their `cosine_similarity` scores rounded to 4 decimals, sorted highest first — read the scores off the returned array rather than assuming an order.

**6.** Define the `AgentState` `TypedDict` with the keys `question`, `retrieved_facts`, `grade`, `retry_count`, and `final_answer`, then hand-seed a state dictionary with `"question": "How does the Transformer work?"`, `"retrieved_facts": []`, `"grade": ""`, `"retry_count": 0`, `"final_answer": ""` — exactly the initial state the agent is invoked with. Print the keys of `AgentState.__annotations__` in order, then print the seeded dictionary itself.

**7.** Write `retrieve_node(state: AgentState) -> AgentState` from scratch with a new `top_k` parameter defaulting to `2`, embedding the question with `embed_query`, scoring with `cosine_similarity([question_vector], knowledge_vectors)[0]`, and picking indices with `scores.argsort()[-top_k:][::-1]`. Call it on the state from problem 6, then print `Retrieving for: '{state['question']}'`, the number of facts now in `state["retrieved_facts"]`, and — by recomputing the scores — the cosine score of each selected chunk to 4 decimals.

**8.** Write `grade_node(state: AgentState) -> AgentState` from scratch using the softened prompt that asks whether the facts contain ANY relevant hints and demands a one-word `YES` or `NO` reply, and normalize with `state["grade"] = "YES" if "YES" in raw_grade else "NO"`. Run it on the state left by problem 7 and print `Grade: {state['grade']}`.

**9.** Break the guard on purpose: monkeypatch `grade_node` into a second copy that normalizes with `raw_grade.strip() == "YES"` instead of `"YES" in raw_grade`, and feed it three raw replies you fabricate — `"YES"`, `"YES."`, and `"Yes, those facts are useful."`. Print the parsed grade from each, one per line, so the difference between substring matching and exact matching is visible rather than assumed.

**10.** Write `rewrite_node(state: AgentState) -> AgentState` from scratch with the prompt that names the failing question and asks for a clearer rewrite, replacing `state["question"]` and incrementing `state["retry_count"]`. Hand-seed a state with `grade` set to `"NO"`, `retry_count` set to `1`, and the question `"transformer stuff"` and run it, printing `Rewritten question: {state['question']}` and `retry_count: {state['retry_count']}`.

**11.** Write `route_after_grading(state: AgentState) -> str` from scratch with the rule that returns `"generate"` when `state["grade"] == "YES" or state["retry_count"] >= 2` and `"rewrite"` otherwise, then print a full decision table over `grade` values `"YES"` and `"NO"` crossed with `retry_count` values `0`, `1`, `2`, and `3`. After the table, print one line beginning `If the retry clause were removed:` explaining which combination would keep the graph cycling between `grade` and `rewrite` forever.

**12.** Build the graph with `StateGraph(AgentState)`, register the four nodes under the names `retrieve`, `grade`, `rewrite`, and `generate`, wire `START` to `retrieve`, `retrieve` to `grade`, the conditional edge `"grade"` to `route_after_grading` with the mapping `{"generate": "generate", "rewrite": "rewrite"}`, `rewrite` back to `retrieve`, and `generate` to `END`. Print `Agent graph compiled successfully!` and then read back `sorted(agent.get_graph().nodes.keys())` and every edge as `source -> target` on its own line.

**13.** Invoke the compiled `agent` with the initial state from problem 6, then print `result["grade"]` and `result["retry_count"]`, split `result["final_answer"]` on `--- FINAL ANSWER ---` and `--- EXPLAINABILITY ---`, print whether both markers are present, and print the explainability section on its own line.

**14.** Re-run the same question with `agent.stream(initial_state, stream_mode="values")` and print one line per state update containing the snapshot's `question` truncated to 60 characters, its `grade`, its `retry_count`, and `len(retrieved_facts)` — so the number of times the graph actually looped back through `rewrite` is read off the state history rather than guessed from the final result.
