# Lab 7 Assignment: End-to-End Graph RAG — From NetworkX to Neo4j — Coding Problems

Put what you learned in **Lab 7: End-to-End Graph RAG — From NetworkX to Neo4j** into code, but go beyond the lab. The lab asked `nvidia/nemotron-3-super-120b-a12b:free` (through OpenRouter) once for `source`/`relation`/`target` triples, built an in-memory NetworkX graph and walked it up to 2 hops, then wrote the same triples into Neo4j Aura with `MERGE`, read them back with Cypher, and answered the same question both ways with a `--- FINAL ANSWER ---` block followed by a `--- AI TRACING & EXPLAINABILITY ---` block. The problems below rebuild that chain from scratch in two parts: problems 1-7 cover the PDF, the triples, and the NetworkX graph; problems 8-14 cover Neo4j, Cypher, and the answer. Along the way you cap the number of triples, break the JSON parser on purpose, compare 1-hop and 2-hop walks, prove `MERGE` never duplicates a node, and reopen the database through a second connection to prove the graph outlives the session. Write each problem from scratch in a scratch Python file. Each problem says exactly what to print; print it.

**1.** Write the bootstrap: read `OPENROUTER_API_KEY`, `NEO4J_URI`, `NEO4J_USERNAME`, and `NEO4J_PASSWORD` from the environment (load a `.env` file with `python-dotenv` first), assert that all four are non-empty, and print `✓ All environment variables loaded successfully`. Then write `ask_llm(prompt: str) -> str` that posts one user message to `https://openrouter.ai/api/v1/chat/completions` with model `nvidia/nemotron-3-super-120b-a12b:free`, `temperature=0.0`, and `"reasoning": {"enabled": False}`, and returns the reply text. Call it with `"Reply with the single word: ready"` and print the reply.

**2.** Write `download_pdf(url: str, path: str) -> int` that creates the folder with `os.makedirs(..., exist_ok=True)`, downloads `https://arxiv.org/pdf/1706.03762.pdf` with `requests.get`, calls `raise_for_status()`, writes the bytes to `data/document.pdf`, and returns the number of bytes written. Print the byte count and the exact line `Success! PDF stored at: data/document.pdf`.

**3.** Write `extract_first_page_text(pdf_path: str, char_limit: int = 1500) -> str` using `PyPDF2.PdfReader` and `reader.pages[0].extract_text()`, trimming with `[:char_limit].strip()`. Call it on `data/document.pdf` and print `Success! Extracted {len(text)} characters.` followed by the first 80 characters of the text on their own line.

**4.** Write `extract_graph_elements(text: str, max_triples: int = 12) -> list[dict]` using `ask_llm`: the prompt must demand a pure JSON list of objects with keys `source`, `relation`, and `target`, and say to return at most `max_triples` entries. Strip a leading markdown fence the way the lab does before calling `json.loads`, and on any exception print `Extraction Error: {error}` and return `[]`. Call it once on the text from problem 3, store the result in `triples`, and print the count plus the first triple as `json.dumps(triples[0], indent=2)`. Reuse `triples` in every later problem; do not call the LLM for extraction again.

**5.** Break the parser on purpose: write `parse_raw_json(raw: str) -> list` that calls `json.loads(raw)` with no fence-stripping inside a `try`/`except`, printing `Extraction Error: JSONDecodeError` and returning `[]` on failure. Feed it a fake reply that wraps valid JSON in a fenced `json` block, print that it returned `[]`, then feed it the same JSON without the fence and print the length of the list it returns.

**6.** Write `build_graph(triples: list[dict]) -> nx.DiGraph` that strips each field and calls `G.add_edge(source, target, relation=relation)`. Build the graph from `triples` and print `Graph built: {G.number_of_nodes()} nodes, {G.number_of_edges()} edges`. Then print the node with the highest out-degree and its out-degree on one line as `Most connected: {node} ({degree} outgoing edges)`.

**7.** Write `find_node_in_question(question: str, node_names) -> str | None` that returns the longest node name whose lowercase form appears in the lowercase question, or `None`. Call it with `G.nodes` for `"What mechanism does the Transformer architecture rely on?"` and print `Detected concept: {name}`. Then call it with `"What is the price of coffee in Zurich?"` and print exactly `Could not find any known concepts in your question.` Finish with one printed sentence explaining why a substring match fails when a question uses a synonym instead of the literal node name.

**8.** Write `traverse_subgraph(graph: nx.DiGraph, start_node: str, radius: int = 2) -> list[str]` using `nx.single_source_shortest_path_length(graph, start_node, cutoff=radius)` and `graph.subgraph(...)`, returning facts formatted as `{u} --[{relation}]--> {v}`. Call it for `"Transformer"` with `radius=1` and `radius=2`, print both fact counts, then print the number of facts that appear only in the `radius=2` result. If the two counts are equal, print one sentence explaining why (hint: a `DiGraph` walk follows arrows forward only).

**9.** Write `answer_from_facts(question: str, facts: list[str]) -> str` that builds a bullet-list `facts_block` with `- ` prefixes, asks `ask_llm` to answer using ONLY those facts in exactly two sections, `--- FINAL ANSWER ---` and `--- AI TRACING & EXPLAINABILITY ---`, and forbids first-person pronouns in the trace. Wrap the call in `try`/`except` returning `Error executing Graph RAG: {error}` on failure. Then write `execute_graph_rag(question: str) -> str` that finds the node (problem 7), prints `[System Log] Auto-detected focus concept: '{entity}'`, walks the NetworkX graph with `radius=2`, and answers. Call it with the Transformer question and print the result, then print two booleans on separate lines: whether the text contains `--- FINAL ANSWER ---` and whether it contains `--- AI TRACING & EXPLAINABILITY ---`.

**10.** Write `normalize_relation(relation: str) -> str` that reproduces the lab's clean-up for Neo4j relationship types (strip, replace spaces and hyphens with underscores, uppercase) using a single `re.sub` call. Apply it to `"has author"`, `"is-a-type-of"`, and `"part of"` and print the three results on separate lines. Then write one sentence (printed) explaining why the relationship type is placed into the Cypher text with an f-string while the entity names are passed as `$source` and `$target` parameters.

**11.** Write `write_triples(tx, triples: list[dict]) -> int` that, for each triple, runs exactly one Cypher query containing `MERGE (s:Concept {name: $source})`, `MERGE (t:Concept {name: $target})`, and `MERGE (s)-[:{relation_type}]->(t)` (using `normalize_relation`), and returns the number of `tx.run` calls made. Open a driver with `GraphDatabase.driver(NEO4J_URI, auth=(NEO4J_USERNAME, NEO4J_PASSWORD))`, call `driver.verify_connectivity()`, clear the database with `MATCH (n) DETACH DELETE n`, and load your `triples` with `session.execute_write(write_triples, triples)`. Print the number of queries run.

**12.** Prove `MERGE` is idempotent: run `session.execute_write(write_triples, triples)` a second time with the same triples, then run `MATCH (n:Concept) RETURN count(n) AS c` and `MATCH ()-[r]->() RETURN count(r) AS c`. Print `Neo4j: {n} nodes, {r} relationships`, then print `Same node count as NetworkX: {n == G.number_of_nodes()}` and `Safe to re-ingest: True` only if the node count did not change between the first and second load (compute it; do not hard-code the line).

**13.** Write two functions from scratch. `fetch_node_names() -> list[str]` runs `MATCH (c:Concept) RETURN c.name AS name` and returns the names. `fetch_graph_context(entity_name: str, hops: int = 2) -> list[str]` runs a variable-length Cypher pattern `MATCH p = (n:Concept {name: $name})-[*1..{hops}]-(m:Concept)` followed by `UNWIND relationships(p) AS r` and `RETURN DISTINCT startNode(r).name AS source, type(r) AS relation, endNode(r).name AS target`, formatting each row as `{source} --[{relation}]--> {target}` (wrap `hops` in `int()` before putting it in the query text). Reuse `find_node_in_question` with `fetch_node_names()` to detect `"Transformer"`, then print the fact counts for `hops=1` and `hops=2`, and the number of facts unique to `hops=2`.

**14.** Write `execute_neo4j_rag(question: str) -> str` that reuses `find_node_in_question`, `fetch_node_names`, `fetch_graph_context(hops=2)`, and the same `answer_from_facts` from problem 9 (do not redefine it). Print `[System Log] Auto-detected focus concept: '{entity}'`, answer the Transformer question, and print the result. Then reopen the database through a second, independent `GraphDatabase.driver(...)`, count the `Concept` nodes through it, and print `Persistence check: {count}`. Finally close both drivers with `driver.close()`.
