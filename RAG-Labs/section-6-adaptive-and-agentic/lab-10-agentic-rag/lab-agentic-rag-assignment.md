# Lab 10 Assignment: Agentic RAG — Coding Problems

Put what you learned in **Lab 10: Agentic RAG** into code — but go beyond the lab. The lab built a LangGraph agent that retrieves chunks with `cosine_similarity`, grades them with an LLM, and rewrites the question when the grade is `NO` (Part 1), then added a Neo4j graph tool, a `router_node`, and a `fallback_node` that swaps tools before it rewrites (Part 2). The problems below push past that: they hand-seed states the graph never produced, break the grade guard and the retry cap on purpose, watch the loop's intermediate states instead of trusting the final one, read the Neo4j graph back out of the database, and force the router and the fallback to show their behaviour. Write each problem from scratch in a scratch Python file. Each problem says exactly what to print; print it.

**1.** Write the environment bootstrap: load `.env` with `python-dotenv`, then assert `OPENROUTER_API_KEY`, `NEO4J_URI`, `NEO4J_USERNAME`, and `NEO4J_PASSWORD` are all set and non-empty. Print `✓ All environment variables loaded successfully`.

**2.** Configure `ChatOpenAI` with `openai_api_key=os.getenv("OPENROUTER_API_KEY")`, `openai_api_base="https://openrouter.ai/api/v1"`, `model_name="nvidia/nemotron-3-super-120b-a12b:free"`, `temperature=0.0`, and `extra_body={"reasoning": {"enabled": False}}`, plus `HuggingFaceEmbeddings(model_name="all-MiniLM-L6-v2")`. Print `LLM and embedding model configured successfully!`, the client's `model_name`, and the length of the vector returned by `embeddings.embed_query("attention")`.

**3.** Download `https://arxiv.org/pdf/1706.03762.pdf` into `data/downloaded_paper.pdf` (create the folder with `os.makedirs("data", exist_ok=True)` first), extract the first 1500 characters into `document_text`, and print `Extracted {len(document_text)} characters of text.` and, on the next line, the first 80 characters of `document_text`.

**4.** Split `document_text` with `RecursiveCharacterTextSplitter(chunk_size=300, chunk_overlap=50, separators=["\n\n", "\n", ".", " ", ""])` into `knowledge_base` and print `Knowledge base ready with {len(knowledge_base)} chunks.` Then check whether the last 50 characters of `knowledge_base[0]` appear inside `knowledge_base[1]` and print `Overlap preserved: True` or `Overlap preserved: False`. Finally embed the chunks with `embed_documents` into `knowledge_vectors` and print the vector length of the first chunk.

**5.** Write `vector_search(question: str, top_k: int = 2) -> list` from scratch: embed the question, score it against `knowledge_vectors` with `cosine_similarity`, and pick indices with `scores.argsort()[-top_k:][::-1]`. Call it with `"How does the Transformer work?"` and `top_k=3`, and print each returned chunk's index (found by looking it up in `knowledge_base`) with its cosine score to 4 decimals, highest first. Then call it with `"What is the boiling point of liquid nitrogen?"` and print the top score, so you can compare a good match with a poor one.

**6.** Define the `AgentState` `TypedDict` with the keys `question`, `retrieved_facts`, `grade`, `retry_count`, and `final_answer`, plus `new_state(question, **extra)` that returns a fresh state dictionary. Print the keys of `AgentState.__annotations__` in order, then print `new_state("transformer stuff")`. Then define `RoutedState(AgentState)` with one extra key `current_tool` and print the keys of `RoutedState.__annotations__`, so you can see that it inherits the first five.

**7.** Write `grade_node(state)` from scratch using the softened prompt that asks whether the facts contain ANY relevant hints and demands a one-word `YES` or `NO`, normalizing with `"YES" if "YES" in raw_grade else "NO"`. Run it twice with hand-seeded states: the question `"How does the Transformer work?"` with the facts from problem 5, and the question `"What is the boiling point of liquid nitrogen?"` with the same facts. Print `Grade: {state['grade']}` for each, one per line.

**8.** Break the grade guard on purpose: write a second parser that uses `raw_grade.strip() == "YES"` instead of `"YES" in raw_grade`, and feed both parsers three raw replies you fabricate — `"YES"`, `"YES."`, and `"Yes, those facts are useful."` (upper-case them first). Print one line per reply showing both parsed grades, so the difference between substring matching and exact matching is visible rather than assumed.

**9.** Write `rewrite_node(state)` from scratch with the prompt that names the failing question and asks for a clearer rewrite, replacing `state["question"]` and incrementing `state["retry_count"]`. Hand-seed a state with `grade` set to `"NO"`, `retry_count` set to `1`, and the question `"transformer stuff"`, run it, and print `Rewritten question: {state['question']}` and `retry_count: {state['retry_count']}`.

**10.** Write `route_after_grading(state) -> str` that returns `"generate"` when `state["grade"] == "YES" or state["retry_count"] >= 2` and `"rewrite"` otherwise. Print a full decision table over `grade` values `"YES"` and `"NO"` crossed with `retry_count` values `0`, `1`, `2`, and `3`. After the table, print one line beginning `If the retry clause were removed:` explaining which combination would keep the graph cycling between `grade` and `rewrite` forever.

**11.** Write `retrieve_node` and `generate_node` from scratch (retrieve calls your `vector_search`; generate asks for the `--- FINAL ANSWER ---` and `--- EXPLAINABILITY ---` sections and says to answer from the facts only). Build the Part 1 graph with `StateGraph(AgentState)` using nodes `retrieve`, `grade`, `rewrite`, `generate`, the conditional edge from `grade` with mapping `{"generate": "generate", "rewrite": "rewrite"}`, and `rewrite` back to `retrieve`. Print `Self-correcting agent compiled successfully!`, then `sorted(agent.get_graph().nodes.keys())`, and every edge as `source -> target` on its own line.

**12.** Stream the Part 1 agent twice with `agent.stream(new_state(q), stream_mode="values")` — once for `"How does the Transformer work?"` and once for `"What is the boiling point of liquid nitrogen?"` — and print one line per state update with the snapshot's `question` truncated to 60 characters, its `grade`, its `retry_count`, and `len(retrieved_facts)`. After each run print `Loop-backs through rewrite: {n}`, read off the state history rather than guessed from the final result, and confirm the second run stops at `retry_count == 2`.

**13.** Connect to Neo4j with `GraphDatabase.driver(...)` and `verify_connectivity()`, clear the database, ask the LLM to extract `{"nodes": [...], "relationships": [...]}` JSON from `document_text` (slice from the first `{` to the last `}` before `json.loads`), write it with `MERGE`, wrapping each relationship type in backticks, and build the `concept_embeddings` vector index with 384 dimensions and cosine similarity, embedding every `Concept`. Then read the graph back out of the database rather than from the extraction log: print the node count from `MATCH (n:Concept) RETURN count(n)`, then each relationship type with its count, highest first, from `MATCH ()-[r]->() RETURN type(r), count(*)`. Print one line comparing the number of relationships the LLM returned with the number actually stored, and say in that line why they can differ.

**14.** Write `graph_search(question) -> list` that queries `concept_embeddings` for the 2 nearest concepts and walks one step along their relationships, returning lines shaped like `seed --[TYPE]-> neighbor` (at most 5), or `["No relevant information found in Neo4j."]` when nothing comes back. Call it and `vector_search` on the same question, `"What models or mechanisms are sequence transduction models based on or connected to?"`, and print both result lists under the headings `VECTOR:` and `GRAPH:`. Then call `graph_search` on `"zzzz"` and print how many results came back.

**15.** Write `router_node` (VECTOR for meanings and definitions, GRAPH for connections and relationships, defaulting to VECTOR unless `"GRAPH"` appears in the reply) and `fallback_node` (swap the tool when `retry_count == 0`, otherwise reuse your `rewrite_node`; both branches increment `retry_count`). Call `router_node` on three hand-seeded `RoutedState`s — `"What is the Transformer?"`, `"How is the encoder connected to the decoder?"`, and `"What is the boiling point of liquid nitrogen?"` — and print each question with the tool chosen. Then call `fallback_node` on one state with `retry_count=0` and `current_tool="GRAPH"` and one with `retry_count=1`, printing the tool, question, and `retry_count` after each call.

**16.** Build the Part 2 graph with `StateGraph(RoutedState)` and nodes `router`, `retrieve` (a `routed_retrieve_node` that calls `graph_search` or `vector_search` by `current_tool`), `grade`, `fallback`, `generate`, reusing your `route_after_grading` with the mapping `{"generate": "generate", "rewrite": "fallback"}`. Print `Routed agent compiled successfully!` and the edges as `source -> target`. Then stream the three questions from problem 15 with `stream_mode="values"`, printing for each the tools used in order (from `current_tool` in each snapshot), the final `retry_count`, and the first 80 characters of the final answer. Finish with one line stating which question triggered a tool swap and which triggered a rewrite.

Keep each solution to a scratch Python file you can re-run; do not paste the lab's code. Where a problem says to print a table or a count, compute it from the objects you built, not from memory.
