# Assignment: Agentic RAG — Coding Problems

Put what you learned in **Agentic RAG** into code — but go beyond the lab. The lab built a LangGraph agent that retrieves chunks with `cosine_similarity`, grades them with an LLM, and rewrites the question when the grade is `NO` (Part 1), then added a Neo4j graph tool, a `router_node`, and a `fallback_node` that swaps tools before it rewrites (Part 2). Write each problem from scratch in a scratch Python file you can re-run; do not paste the lab's code. Each problem says exactly what to print; print it. Where a problem asks you to predict first, write the prediction as a comment before you run the code.
