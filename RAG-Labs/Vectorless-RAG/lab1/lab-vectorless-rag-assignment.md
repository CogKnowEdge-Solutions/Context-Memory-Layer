# Lab 10 Assignment: Vectorless RAG: Reasoning-Based Retrieval without Embeddings — Coding Problems

Put what you learned in **Lab 10: Vectorless RAG: Reasoning-Based Retrieval without Embeddings** into code — but go beyond the lab. The lab built a two-stage pipeline where `PageIndexClient.submit_document` plus a poll on `is_retrieval_ready` turns the NASA ISS factsheet into a hierarchical tree, the LLM reads only `node_id`/`title`/`summary` to pick a `node_list`, and `pymupdf` extracts the raw page text that the LLM finally answers from — no embeddings anywhere. The problems below rebuild that pipeline function by function, cap and re-word the extraction prompt, break `utils.remove_fields` by forgetting the `.copy()` so you can watch it mutate the original tree, force the `json.JSONDecodeError` path so the regex fallback actually runs, sweep `top_k`-style variations and swap `call_llm`'s `model` from Amazon Nova Lite to Claude Haiku and Sonnet to compare which sections each one selects, and add the empty-`node_list` branch the lab never reaches. Write each problem from scratch in a scratch Python file. Each problem says exactly what to print; print it.

**1.** Write the environment bootstrap: set `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`, `AWS_ENDPOINT_URL`, and `AWS_REGION` as environment variables, prompt for the PageIndex key with `input()` and store it in `PAGEINDEX_API_KEY`, then assert all five are non-empty and instantiate `pi = PageIndexClient(api_key=PAGEINDEX_API_KEY)`. Print the line `Credentials configured.` followed by `PageIndex key loaded.` and `Vectorless RAG environment ready.`

**2.** Write the download step from scratch: `requests.get` the URL `https://www.nasa.gov/pdf/65431main_ffs_factsheets_issoverview.pdf`, call `response.raise_for_status()`, `os.makedirs("data", exist_ok=True)`, and write the bytes to the path `data/iss_overview.pdf`. Print `Downloaded PDF ({len(response.content)} bytes) to data/iss_overview.pdf`.

**3.** Write `wait_for_tree(client, doc_id, timeout=300, poll=5) -> int` from scratch: loop while `elapsed < timeout`, break when `client.is_retrieval_ready(doc_id)` returns truthy, `time.sleep(poll)` otherwise, and raise `TimeoutError("PageIndex timeout")` when the loop exhausts. Submit the PDF with `pi.submit_document(PDF_PATH)`, pass the returned `doc_id` to your function, and print `Submitted: {doc_id}` and the number of seconds it waited as `Tree ready after {elapsed}s`.

**4.** Write a recursive `count_nodes(node) -> int` that returns `1` for a leaf and `1 + sum(count_nodes(c) for c in node.get("children", []))` otherwise. Fetch the tree with `pi.get_tree(doc_id, node_summary=True)["result"]`, render it with `utils.print_tree(tree, exclude_fields=["text"])`, and print the total node count, the root's `node_id`, and the root's `title`.

**5.** Deliberate debugging exercise on the PageIndex utilities: call `utils.remove_fields(tree, fields=["text"])` **without** the `.copy()` the lab uses, then inspect the original `tree` object and count how many nodes still expose a `text` key. Print `Original tree still has text: {count}` and one following line naming the change that makes this safe.

**6.** Write `search_nodes(tree, query, model="global.amazon.nova-2-lite-v1:0") -> dict` from scratch: build `tree_slim = utils.remove_fields(tree.copy(), fields=["text"])`, embed it as JSON in a prompt that demands a reply of exactly `{"thinking": "...", "node_list": ["node_id_1"]}`, call `call_llm(search_prompt, model=model)` with `temperature=0` and `max_tokens=512`, and parse with `json.loads` plus the `re.search(r'\{.*\}', response, re.DOTALL)` fallback. Run it with the query `"What is the purpose of the International Space Station?"` and print the first 200 characters of the `thinking` field and the `node_list` on the next line.

**7.** Force the fallback branch on purpose: reuse the parsing code from problem 6 but change the prompt to end with `Respond in three plain English sentences. No JSON.` and do not use the regex fallback. Wrap the call in `try`/`except json.JSONDecodeError`, print `Could not parse LLM response. Using empty result.`, and print `Regex fallback used: False` to record that the fallback was deliberately skipped.

**8.** Write `report_nodes(result, tree) -> int` from scratch using `utils.create_node_mapping(tree, include_page_ranges=True)`: for each id in `result["node_list"]` print `{nid} | Pages {pages} | {title}` where `pages` is a single number when `info['start_index'] == info['end_index']` and a `{start}-{end}` range otherwise, printing `{nid} | not found in tree` for any id absent from the mapping. Return the number of ids printed and print `Retrieved nodes: {count}`.

**9.** Write `extract_pages(pdf_path) -> dict` from scratch with `pymupdf.open` and `doc.load_page(i).get_text()`, building a dictionary keyed by 1-based page numbers, then `doc.close()`. Print `Extracted text from {len(page_texts)} pages.` and, on separate lines, the total character count across all pages and the character count of page 1 alone.

**10.** Write `build_context(node_list, node_map, page_texts) -> tuple[str, list[int]]` from scratch: for each selected id look up `info["node"].get("page_index")`, skip ids missing from `node_map` or pointing at pages not in `page_texts`, skip any page already added to a `seen` set, and append `f"--- Page {page} ---\n{page_texts[page]}"` otherwise. Return the `"\n\n".join(...)` context and the sorted list of pages used, then print `Pages used: {pages}`, `Using {len(context.splitlines())} lines of text.`, and a line asserting `No duplicate pages: {pages == sorted(set(pages))}`.

**11.** Write `answer_from_context(context, query) -> str` from scratch: send a prompt containing the `Context:`, the `Question:`, and the three rules `Answer only from the context`, `If the answer isn't there, say so`, and `Be concise`, to `call_llm` with the default model `global.amazon.nova-2-lite-v1:0`. Run it with the context from problem 10 and the query `"What is the purpose of the International Space Station?"`, print the answer, then print one extra line reporting whether the string `I don't know` appears in it.

**12.** Write `compare_page_coverage(context, page_texts) -> tuple[list[int], list[int]]` from scratch: scan `context` for every `--- Page {n} ---` marker and return the pages the retrieval step actually included and the pages from `page_texts` that were skipped. Print `Pages retrieved: {retrieved}` and `Pages skipped: {skipped}` for the run from problem 10, then print one line explaining in a single sentence what happens to an answer whose evidence sits entirely on a skipped page.

**13.** Collapse the lab's four steps into one function `run_vectorless_rag(query, tree, page_texts) -> str` that runs the slim-tree search, the node mapping, the context build, and the answer, printing a stage label before each stage as `--- Stage 1: node selection ---`, `--- Stage 2: context build ---`, and `--- Stage 3: answer ---`. Add the branch the lab never reaches: when `result["node_list"]` is empty, return immediately after printing `No relevant sections found in the tree.` Call it once with the real query and once with a forced empty `node_list`, and print both outcomes.

**14.** Swap the model and compare, change one thing at a time: call `search_nodes` from problem 6 three times for the same query — with `global.amazon.nova-2-lite-v1:0`, with `global.anthropic.claude-haiku-4-5-20251001-v1:0`, and with `global.anthropic.claude-sonnet-4-5-20250929-v1:0` — and print each model name followed by the node ids it selected. Then print a single line stating whether all three runs agreed on the same `node_list`, and if not, which model picked a strictly larger set.
