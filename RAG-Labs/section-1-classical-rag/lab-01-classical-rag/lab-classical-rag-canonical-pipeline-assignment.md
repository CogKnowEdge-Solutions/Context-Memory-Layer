# Lab 1 Assignment: Classical RAG: The Canonical Pipeline — Coding Problems

Put what you learned in **Lab 1: Classical RAG: The Canonical Pipeline** into code — but go beyond the lab.

The lab reads a two-page text file with `pathlib.Path(...).read_text()`, wraps each page in a `Document` by hand, cuts the text into 400-character chunks with 50 characters of overlap using `RecursiveCharacterTextSplitter`, embeds every chunk with `all-MiniLM-L6-v2` via `HuggingFaceEmbeddings`, stores the vectors with `FAISS.from_documents` using `distance_strategy=DistanceStrategy.MAX_INNER_PRODUCT` (a FAISS `IndexFlatIP`), retrieves the top-3 with `similarity_search_with_score`, and asks an OpenRouter model to answer from those chunks alone.

The problems below pull every stage apart so you can measure it on its own — count chunks, prove the score really is a cosine, turn the retriever loose on questions the document cannot answer, and then break the settings you copied to find out what they were quietly protecting you from.

**How to work**

- Write each problem **from scratch** in a scratch Python file. Do not copy-paste the lab's cells wholesale — the point is to rebuild each stage yourself.
- Each problem names **exactly what to print**. Print it, with that exact wording.
- Run everything in the lab folder so `data/sample_text_document.pdf` and `.env` resolve.
- Every problem reuses the objects you built in the lab: `pages`, `chunks`, `embedding_model`, `vector_store`, `QUESTION`, `matches`, `llm`, `rag_prompt`.

**A warning that applies to most of these problems:** with the lab's `MAX_INNER_PRODUCT` index, the score `similarity_search_with_score` hands you **is already the cosine similarity** — `1` identical, `0` unrelated, `-1` opposite, and **higher is better**. Do not convert it. Where a problem says "similarity" or "cosine", just print the number.

The trap runs the other way, and it is worth internalising before problem 5: LangChain *also* offers a strategy named `DistanceStrategy.COSINE`, and on this version of `langchain-community` it builds an `IndexFlatL2` and returns **squared straight-line distance** instead — lower is better, `0.457` where the cosine is `0.771`. Problems 5 and 6 exist to let you see that arithmetic rather than take it on faith.
