# Lab 4 Assignment: ColBERT & Late Interaction RAG — Coding Problems

Put what you learned in **Lab 4: ColBERT & Late Interaction RAG** into code — but go beyond the lab. The lab embeds every token of every chunk with `colbert-ir/colbertv2.0`, stores the resulting `(num_tokens, 128)` matrices in a Qdrant `MAX_SIM` multivector collection, and answers a BERT-paper question through a late-interaction search plus an LCEL chain. The problems below add a hand-written MaxSim implementation so you can see the three scoring steps yourself, read the collection config and point count back out of Qdrant, sweep `top_k` to show what changes, and break the pipeline twice — once by feeding `colbert.embed` a bare string and once by dropping `multivector_config` from the collection. Write each problem from scratch in a scratch Python file. Each problem says exactly what to print; print it.

**1.** Write the environment bootstrap: call `load_dotenv()`, then assert that `os.environ["OPENROUTER_API_KEY"]`, `os.environ["QDRANT_URL"]`, and `os.environ["QDRANT_API_KEY"]` are all non-empty, and print `✓ All environment variables loaded successfully`.

**2.** Configure both models from scratch: build `colbert = LateInteractionTextEmbedding("colbert-ir/colbertv2.0")` and `llm = ChatOpenAI(openai_api_key=os.getenv("OPENROUTER_API_KEY"), openai_api_base="https://openrouter.ai/api/v1", model_name="nvidia/nemotron-3-super-120b-a12b:free", temperature=0.0)`. Print `ColBERT model: colbert-ir/colbertv2.0` and `LLM: nvidia/nemotron-3-super-120b-a12b:free` after the first `colbert.embed` call returns, so you know the local model actually downloaded.

**3.** Rebuild the ingestion step: set `PDF_URL = "https://arxiv.org/pdf/1810.04805.pdf"`, download it with `requests.get` and call `response.raise_for_status()`, write the bytes to `PDF_FILENAME = "bert_paper.pdf"`, then open it with `PdfReader` and build `raw_text` by joining `page.extract_text()` for every page with newlines. Print `Downloaded bert_paper.pdf.` and then `Extracted {len(raw_text)} characters.`.

**4.** Chunk the same `raw_text` twice: once with `RecursiveCharacterTextSplitter(chunk_size=500, chunk_overlap=50)` and once with `chunk_size=200, chunk_overlap=20`. Print `Created {len(chunks_500)} chunks at chunk_size=500.` and `Created {len(chunks_200)} chunks at chunk_size=200.`, then one line computing and printing `Ratio 500 vs 200: {ratio:.2f}x` from the two lengths.

**5.** Implement MaxSim yourself with no Qdrant involved: write a `maxsim(query_matrix, doc_matrix)` function that takes two `(num_tokens, 128)` matrices, L2-normalizes every row, takes the full `query_matrix @ doc_matrix.T` grid of pairwise cosine similarities, keeps only `max` along the document axis per query token, and returns the array of kept maxima plus their `sum`. Run it on the `colbert.query_embed("What pre-training tasks")` matrix against the `colbert.embed` matrix of the first chunk containing the phrase `masked language models`, print `Per-query-token best scores: [...]`, print `MaxSim score = {total:.2f}`, and print which document-token index each query token matched.

**6.** Sanity-check the token matrices on the first five chunks: run `chunk_embeddings = list(colbert.embed(chunks_500[:5]))`, print `Chunk {i} shape: {shape}` for each, then assert every matrix has 128 columns and print `✓ All 5 matrices are (num_tokens, 128) token matrices, not single vectors.`. **7.** Break the embedding call deliberately: call `colbert.embed("masked language models")` with a bare string instead of a list of chunks inside a `try` / `except Exception`, then print `Caught: {type(e).__name__}` and the first 200 characters of `str(e)`. **9.** Create the collection from scratch with `client.recreate_collection(collection_name=COLLECTION_NAME, vectors_config=models.VectorParams(size=128, distance=models.Distance.COSINE, multivector_config=models.MultiVectorConfig(comparator=models.MultiVectorComparator.MAX_SIM)))` where `COLLECTION_NAME = "colbert_late_interaction"`, then read the configuration back with `client.get_collection(COLLECTION_NAME)` and print `Vector size: {config.params.vectors.size}`, `Distance: {config.params.vectors.distance}`, and `Comparator: {config.params.vectors.multivector_config.comparator}`.

**10.** Ingest and verify: build the `points` list of `models.PointStruct(id=stable_id(chunk), vector=embedding.tolist(), payload={"text": chunk})` for every chunk, upload with `client.upload_points(collection_name=COLLECTION_NAME, points=points, batch_size=10)`, and print `Uploaded {len(points)} ColBERT points.`.
